# 🚗 Car Sales Performance Analysis (Power BI)

## 📌 Project Overview
This project involved developing a comprehensive interactive dashboard to analyze car sales data. The goal was to provide a dealership management team with insights into sales trends, profitability by car model, and regional performance to drive data-backed decision-making.

## 📊 Key Insights & Features
* **Sales Overview:** Tracked Total Revenue, Average Sales Price, and Units Sold.
* **Trend Analysis:** Built a Year-to-Date (YTD) and Month-to-Date (MTD) comparison to identify growth patterns.
* **Regional Performance:** Created a map visualization to pinpoint high-performing geographic clusters.
* **Product Deep-Dive:** Analyzed the most popular body styles (SUV, Sedan, Hatchback) and top-selling car models.
* **Interactivity:** Implemented slicers for Date, Region, and Dealer, allowing users to filter data dynamically.

## 🛠️ Technical Skills Demonstrated
- **Data Modeling:** Created relationships between sales tables and date tables.
- **DAX (Data Analysis Expressions):** Wrote custom measures for YTD Sales, Growth %, and Rolling Averages.
- **Data Cleaning:** Used Power Query to handle missing values and format data types.
- **Visualization:** Utilized advanced charts (Matrix, Donut, KPI Cards, and Map visuals).
